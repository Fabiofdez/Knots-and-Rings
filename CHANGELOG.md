### Changes
- Full revamp of connected tree rings: With behavior inspired by giant mushroom blocks, tree trunks' interiors now behave more realistically
- Tree ring shapes now persist when nearby logs are broken, and exposed tree ring sides can be healed with bonemeal
- Tree rings now also persist when logs are stripped, meaning that stripped logs can have the same connected shapes
- Stripped logs can thus now also be "split" with a pickaxe to separate the tree ring shapes
- Many features formerly dependent on ctm/fusion are now built-in using models and blockstates
